# SIMKOS PBL

Mulai dari [AGENTS.md](AGENTS.md) untuk panduan kerja kontributor/agen. Dokumentasi struktur, alur role, setup lokal, dan pekerjaan lanjutan ada di [DOKUMENTASI_PENGEMBANGAN.md](DOKUMENTASI_PENGEMBANGAN.md).

Login bersama berada di `auth/login.php`; sistem mengarahkan admin, penghuni, dan calon penghuni ke dashboard masing-masing. Untuk simulasi, aktivitas transaksi dibatalkan saat browser di-refresh. Jalankan pergantian role di browser yang sama agar semua perubahan simulasi tercatat dalam satu sesi.
